# Janet's Law

年齢によって異なる時間の感じ方を、時計とプログレスバーで視覚化する小さなWebアプリです。

## Live Demo

https://yumihiko.github.io/Janetslow/

## How to Use

1. **Start** をクリックすると、各年代の時間の進み方が同時に始まります。
2. 各時計の針とプログレスバーが、年代ごとの知覚時間を表します。
3. **Reset** をクリックすると、すべての時計とバーが初期状態に戻ります。

## Concept

> Janet's Law
> Psychological time passes faster as age increases.

Each clock demonstrates the perceived speed of time for each age group.
